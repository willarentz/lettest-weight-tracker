# Lettest – Issue Tracker

This repository exists **only** to receive bug reports and feature requests for **Lettest**, a calm weight-tracking app for iPhone and iPad.

The source code is not hosted here.

## Found a bug? Have an idea?

[Open an issue →](https://github.com/willarentz/lettest-weight-tracker/issues/new)

A few things that help:

- **What you tried** – the steps that led to the problem.
- **What you expected** – what should have happened.
- **What actually happened** – including any error message text.
- **Device + iOS version** – e.g., "iPhone 15, iOS 17.4". Settings → General → About has both.
- **Screenshots** – paste them straight into the issue.

## Privacy

Filing an issue is public by design — anyone with a link can read it. Don't paste personal data (full name, address, email) you'd rather keep private. The app itself never asks for or receives any of that.

## Contact

This repo's Issues tab is the only contact channel.
